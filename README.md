## 🧠 فلسفه چالش: عضله‌سازی به جای میان‌بر

همه می‌دانیم که کپی کردن صورت‌مسئله در ChatGPT یا Claude و گرفتن یک کد کارآمد فقط چند ثانیه طول می‌کشد! اما اینجا یک **باشگاه بدنسازی برای مغز شماست**، نه تستِ سرعت هوش مصنوعی.

> 🚫 **قانون نانوشته:** ما اینجا به دنبال "جواب نهایی" نیستیم؛ ما به دنبال **"مسیر رسیدن به جواب"** هستیم.
> اگر ۲ ساعت روی معماری، مصرف حافظه و الگوریتم فکر کنید و دست‌آخر حتی به جواب کامل نرسید، ارزشش برای آینده شغلی شما **۱۰ برابر بیشتر** از کسی است که خروجی هوش مصنوعی را کپی کرده است.

### چرا این چالش‌ها جای پرامپت زدن نیست؟
*   **عضله حل مسئله:** اگر همیشه ابزار (AI) جای شما وزنه بزند، قدرت تحلیلی شما رشد نخواهد کرد.
*   **درک تریدآف‌ها:** مهندسی یعنی "انتخابِ بین بد و بدتر". ما می‌خواهیم بدانیم چرا فلان متد را انتخاب کردید.
*   **دفاع در PR:** ارزش اصلی در توضیحات Pull Request شماست. کد تمیزِِ بی‌توضیح، برای ما ارزشی ندارد.

## 📅 روند برگزاری چالش

| فاز | روز | شرح عملیات |
| :--- | :--- | :--- |
| 📢 **انتشار** | چهارشنبه | رونمایی از مسئله، محدودیت‌ها و معیارهای ارزیابی. |
| 🛠 **کدنویسی** | چهارشنبه تا جمعه | وقت آزاد برای تحقیق، شکست خوردن، و بازسازی راه‌حل. |
| 🚀 **ارسال PR** | تا پایان جمعه | ارسال راه‌حل به همراه مستندات منطقِ پشت کد. |
| 🏆 **اعلام نتایج** | شنبه | معرفی راه‌حل‌های برتر و تحلیل فنی آن‌ها. |

## 🎖 نشان‌های افتخار
ما به دنبال بهترین راه‌حل نیستیم، ما به دنبال **"بهترین مهندس"** هستیم. شما می‌توانید در این زمینه‌ها بدرخشید:

| نشان | تخصص |
| :--- | :--- |
| **Clean Coder** 🧹 | کد خوانا، ساده، ماژولار و قابل نگهداری. |
| **Performance Beast** ⚡ | بهینه‌سازی شده برای حافظه و پیچیدگی زمانی (Big-O). |
| **.NET Craftsman** 🏗️ | استفاده خلاقانه و حرفه‌ای از قابلیت‌های C# و .NET. |

## 📝 چطور مشارکت کنیم؟

1.  **Fork** کردن این مخزن.
2.  ایجاد یک **Branch** اختصاصی برای پیاده‌سازی.
3.  **کدنویسی آگاهانه:** قبل از هر خط کد، فکر کنید.
4.  **ارسال Pull Request:** در توضیحات PR بنویسید که:
    *   چه راه‌هایی را امتحان کردید و چرا شکست خوردند؟
    *   تریدآف‌های (Trade-offs) تصمیمات فنی شما چیست؟
    *   پیچیدگی الگوریتم شما چقدر است؟
5.  **منتظر بمانید:** ما کد شما را با دقت می‌خوانیم و بازخورد می‌دهیم.
