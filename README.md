## 🧠 فلسفه چالش: عضله‌سازی به جای میان‌بر

همه‌مون می‌دونیم کپی‌کردن صورت‌مسئله توی ChatGPT یا Claude و گرفتن یه کد کارراه‌انداز فقط چند ثانیه طول می‌کشه! اما اینجا **باشگاه بدنسازی مغزته**، نه مسابقه‌ی سرعت با هوش مصنوعی.

> 🚫 **قانون نانوشته:** اینجا دنبال «جواب نهایی» نیستیم؛ چیزی که برامون مهمه **«مسیر رسیدن به جوابه»**.
> اگه ۲ ساعت درباره‌ی معماری، مصرف حافظه و الگوریتم فکر کنی و آخرش هم به جواب کامل نرسی، این تجربه برای آینده‌ی کاری‌ات **۱۰ برابر ارزشمندتره** از کپی‌کردن خروجی هوش مصنوعی.

### چرا این چالش‌ها جای پرامپت‌زدن نیستن؟
*   **عضله‌ی حل مسئله:** اگه همیشه ابزار (AI) به‌جات وزنه بزنه، قدرت تحلیل و حل مسئله‌ات رشد نمی‌کنه.
*   **درک تریدآف‌ها:** مهندسی یعنی «انتخاب بین بد و بدتر». می‌خوایم بدونیم چرا این متد رو انتخاب کردی.
*   **دفاع از راه‌حل توی PR:** بخش مهم ماجرا توضیحات Pull Requestته. کد تمیزِ بی‌توضیح برای ما کافی نیست.

## 📅 روند برگزاری چالش

| فاز | روز | چه اتفاقی می‌افته؟ |
| :--- | :--- | :--- |
| 📢 **انتشار** | چهارشنبه | مسئله، محدودیت‌ها و معیارهای ارزیابی رو اعلام می‌کنیم. |
| 🛠 **کدنویسی** | چهارشنبه تا جمعه | وقت داری تحقیق کنی، راه‌حل‌هات رو امتحان کنی و اگه لازم شد از نو بسازیشون. |
| 🚀 **ارسال PR** | تا پایان جمعه | راه‌حلت رو همراه با توضیح منطق پشت کد بفرست. |
| 🏆 **اعلام نتایج** | شنبه | راه‌حل‌های برتر رو معرفی و از نظر فنی بررسی می‌کنیم. |

## 🎖 نشان‌های افتخار
دنبال بهترین راه‌حلِ صرف نیستیم؛ می‌خوایم **مهارت مهندسی** رو هم ببینیم. این‌ها جاهایی‌ان که می‌تونی بدرخشی:

| نشان | تخصص |
| :--- | :--- |
| **Clean Coder** 🧹 | کدی خوانا، ساده، ماژولار و قابل نگهداری. |
| **Performance Beast** ⚡ | بهینه‌سازی از نظر مصرف حافظه و پیچیدگی زمانی (Big-O). |
| **.NET Craftsman** 🏗️ | استفاده‌ی خلاقانه و حرفه‌ای از قابلیت‌های C# و .NET. |

## 📝 چطور مشارکت کنیم؟

1.  از این مخزن **Fork** بگیر.
2.  برای پیاده‌سازی، یه **Branch** جدا بساز.
3.  **با فکر کد بزن:** قبل از نوشتن هر خط، یک‌بار درباره‌ش فکر کن.
4.  **Pull Request بفرست:** توی توضیحات PR بنویس که:
    *   چه راه‌هایی رو امتحان کردی و چرا جواب ندادن؟
    *   تریدآف‌های (Trade-offs) تصمیم‌های فنی‌ات چی‌ان؟
    *   پیچیدگی الگوریتمت چقدره؟
5.  **منتظر بازخورد بمون:** کدت رو با دقت می‌خونیم و بهت بازخورد می‌دیم.
